Prerequisites and setup

You are gathering ingredients before you cook. None of this is coding. You are creating free accounts and installing two programs so Cursor can build SkillSwap on your computer.

2.1 Create your accounts

Three websites. Sign up with an email you actually check — login codes for SkillSwap will arrive there later too, if you use the same address.

GitHub account

What it is: a website where developers store and share code.

Why you need it: SkillSwap’s files will live here. Vercel will watch this folder and put new versions online automatically.

  1. Go to github.com
  2. Click Sign up and verify your email
  3. Choose a professional username. It will appear in URLs, such as github.com/yourname/skillswap

Vercel account

What it is: a service that hosts web apps — it puts them on the internet.

Why you need it: Vercel takes your code from GitHub and gives you a public link, with https included. The free Hobby plan is enough.

  1. Go to vercel.com
  2. Sign up with GitHub (this connects the two accounts)
  3. Authorize access when GitHub asks

Supabase account

What it is: your backend. It stores SkillSwap data and handles student accounts.

Why you need it: without Supabase, Maya’s request would live only in her browser. With it, Alex can see that request from another laptop.

  1. Go to supabase.com
  2. Sign up and verify your email

2.2 Create your Supabase project

An account is your login. A project is the actual kitchen for SkillSwap — one database, one set of user accounts.

  1. Go to the Supabase dashboard
  2. Click New Project
  3. Name it skillswap (or something you will recognize later)
  4. Set a database password and save it somewhere safe. You will not need it for this bootcamp, but you cannot recover it later from the dashboard.
  5. Choose a region close to you and click Create new project. Wait 1–2 minutes.
  6. Open Project Settings → API. You need two values:
    • Project URL — looks like https://abcdefghijk.supabase.co
    • Publishable key — a long string, often starting with sb_publishable_

What are the Project URL and Publishable key?

Think of the Project URL like a mailing address for your database. When SkillSwap wants to read or write a help request, it needs to know where to send the letter.

The Publishable key is public. It is safe to include in frontend code. It is not a password. Supabase uses Row Level Security — rules on each table — to decide who can actually read or write. Think of it like your home address: it is public information, but that does not mean anyone can walk into your house.

If the dashboard also shows a secret or service_role key, do not copy that one. It bypasses the security rules.

  1. Copy both values into a notes app or a text file. You will paste them into the build prompt.
  2. Keep the Supabase dashboard tab open. You will come back to it.

2.3 Install Node.js

What is Node.js?

When students use SkillSwap, the app runs in their browsers. While you are building it, you also need to run code on your computer — to preview the site, install packages, and prepare a deploy. Node.js is the translator that lets your computer understand JavaScript, the language this app is written in.

  1. Go to nodejs.org
  2. Download the LTS version (Long Term Support — the stable one)
  3. Run the installer and accept the defaults
  4. Verify it worked: open your terminal and type node --version. You should see a version number.
node --version

What is a terminal?

The terminal (also called the command line) is a text-based way to give instructions to your computer. Instead of clicking icons, you type commands. It looks intimidating at first. You will only need a few simple ones, and Cursor will often run them for you.

  • Windows: open PowerShell or Command Prompt from the Start menu
  • Mac: open the Terminal app from Spotlight

2.4 Install Cursor

What is Cursor?

Cursor is a code editor — a special text editor designed for writing code. Unlike a regular editor, it has a built-in AI assistant. You describe SkillSwap in plain English. It writes the files. You are directing the AI, not typing React yourself.

  1. Go to cursor.com
  2. Download and install Cursor
  3. Open it and finish the setup wizard
  4. Sign in or create an account when prompted

2.5 Configure Cursor for this project

Cursor already knows a lot about code, but it has a knowledge cutoff. It does not automatically know last month’s Supabase changes. Adding official docs gives the AI a current cheat sheet for authentication, database queries, and Next.js setup. Better docs → better SkillSwap code.

When this helps: tools with recent API changes, or when suggestions look outdated.

When it is less necessary: very common tools (basic React, everyday JavaScript).

Add all three sources this bootcamp uses:

  1. Open Cursor Settings (Ctrl+, on Windows, Cmd+, on Mac)
  2. Go to Features → Docs
  3. Click Add Doc and enter each URL, one at a time:
    • https://supabase.com/docs
    • https://nextjs.org/docs
    • https://tailwindcss.com/docs
  4. Wait for indexing to finish. You should see the names appear in your docs list.

You now have accounts, a database address, Node.js, and a configured editor. Next you will open an empty folder and ask Cursor to build SkillSwap.
